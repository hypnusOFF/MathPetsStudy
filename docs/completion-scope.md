# 本轮固定制作范围

用户授权完成上轮列出的全部缺项，另设只读监管智能体检查范围和复杂度。本轮沿用 C# Core/UI/MAUI、本地 JSON、轻量 CSS/SVG/浏览器声音，不增加服务器、账号、云同步或新动画框架。

- 三宠物独立名字、经验、饱腹、心情、穿搭；主力切换；练习开始锁定奖励宠物。
- 20级、两个进化门槛、旧存档迁移。
- 三槽位换装、购买、背包、卸下、三宠物适配。
- 答对、鼓励、升级反馈绑定学习；动画/声音设置。
- 已选免费课程按知识点映射、外部观看入口、混合版本筛选和课时顺序整理。
- 人教教材十二册核验及证据/未核验标记；补充图形题与教学图示交互。
- 单元关、学期综合关及独立成绩。
- 毛绒画风资源、表情和局部动作、家园道具、短音效。
- 旧文案清理、自动测试、安卓构建与实际设备验收。

配音、背景音乐不是本轮必做项。官方教材访问和安卓设备可用性如受环境限制，须保留真实证据并明确未验收项，不以标题年份或构建成功替代核验。具体结果在交付时更新。

## 交付结果

| 项目 | 本轮结果 |
|---|---|
| 三宠独立培养与主力 | 已实现名字、经验、饱腹、心情、穿搭独立保存；共享积分与库存；练习锁定奖励宠物 |
| 等级与迁移 | 20级、6级/13级进化，不放大体型；Version1自动迁移到Version2并保留旧成就/进化 |
| 三槽换装 | 9件衣饰可购买、穿戴、卸下；恢复默认进化配饰；27组三宠穿搭截图核查 |
| 学习反馈与设置 | 答对/鼓励动作，跨等级升级、跨阶段进化；声音、减少动画开关持久化 |
| 综合关 | 单元与学期综合关开放，涵盖基础题和图形题；独立保存成绩，不覆盖知识点星级 |
| 图形教学与题目 | 补12类交互/图示知识点、36道原题+36道相似题；可拨钟面、画角、选对称点、旋转、分类 |
| 毛绒画风资源 | 无饰底图、闭眼表情、分层耳尾爪动作和闭口咀嚼；9件衣饰图集、14图标图集、3手绘家园、可静音短音效 |
| 视频入口 | 701条分集元数据；156知识点中155有标题/主题候选，跨年级/跨学期单独标注，三上P1–42与P43–100分版，六上课时纠序 |
| 未匹配视频 | 一下“数列与图案数量规律”在已选合集无明确对应，保持空值而不乱挂视频；匹配候选也未逐集教学内容审核 |
| 教材最新版目录 | 未逐册核验：官方电子教材入口405、2024介绍503，2026官方教材介绍成功但无十二册目录；页面明确提示，保留请求证据 |
| 自动检查 | 60项核心测试、原有全流程浏览器检查、新增12类图形/三宠/换装设置专项；54动作组合、6次进化、取消、减少动画、离线资源检查 |
| 安卓 | Debug APK构建及v2/v3签名验证；真机/模拟器运行未验收，当前环境无Android设备或可用模拟器/KVM |

监管智能体只读审查通过，未增加账号、后端、云同步或新动画框架。制作中发现的配饰路径错误、衣服遮嘴、铃铛错位、书包隐藏、图示答案泄露及旧重复扣款路径已修正。
