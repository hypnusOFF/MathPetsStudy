这批资源服务于三只宠物独立培养的方案。素材和动画已完成；当前游戏仍使用原有单宠物系统，独立存档、主力切换、购买和等级解锁需要下一步接入。预览页允许自由试穿，不消耗游戏积分。

## 预览和交付

`src/MathPet.UI/wwwroot/pet-assets/gallery.html` 内嵌全部 SVG、动画样式和清单。保存此 HTML 后即可离线打开，无需服务器、账号、外部字体或 CDN。可切换宠物、阶段、三套家园、头饰/衣服/随身饰品，并播放互动。

生成、校验和打包：

```bash
python3 scripts/generate-pet-assets.py
python3 scripts/generate-pet-assets.py --check
python3 scripts/package-pet-assets.py
```

输出 `artifacts/mathpet-pet-preview.html` 和 `artifacts/mathpet-pet-assets.zip`。GitHub Actions 同时提供名为 `mathpet-pet-assets` 的下载产物；压缩包包含素材、离线预览、清单、本文及概念设计板。浏览器验证使用 `scripts/smoke-pet-assets.cjs`，测试服务器地址可通过 `PET_ASSETS_URL` 指定。

## 接入 C# / Blazor 的约定

资源位于 `wwwroot/pet-assets/`。`manifest.json` 是路径、形态、等级范围、槽位锚点、尺寸和动作时长的唯一清单。角色视框为 `320 × 360`，服饰和图标为 `180 × 180`，家园为 `960 × 600`。

宠物 SVG 已内嵌动画 CSS。需要交互和换装时，将 SVG 内容以内联方式呈现；仅使用 `<img>` 适合显示不换装的待机资源。输入使用清单中的合法标识，不将用户输入直接作为 SVG 内容。

每个宠物包含 `data-layer` 图层：阴影、尾巴、书包槽位、身体、脚、衣服槽位、头、双耳、五官、普通/开心眼睛、普通/咀嚼嘴、头饰槽位、双爪、饰品槽位及爱心、星光、食物、玩具效果。图层没有固定 DOM ID，允许多个宠物同时呈现。

将服饰 SVG 内部图形放进对应槽位，使用清单的锚点和缩放：

```text
translate(anchorX anchorY) scale(scaleX scaleY) translate(-90 -90)
```

头饰槽位位于头部图层内，随头部动作；衣服随身体比例缩放；书包位于身体后方。随身饰品选择书包时使用 `slot-back`，其余使用 `slot-accessory`。更换成长形态后，按新形态清单重新挂载衣服。

根 SVG 的 `data-action` 取值为 `idle / pet / feed / play / correct / encourage / upgrade / evolve`。动作结束后回到 `idle`。进化预览在 1.4 秒时更换到下一个形态，总时长 2.8 秒；正式游戏应只在达到成长分界且成功保存后触发。

`data-motion="reduced"` 关闭运动动画；同时支持系统 `prefers-reduced-motion`。待机有轻微呼吸、眨眼和尾巴动作，无需 GIF、视频或逐帧位图。特效直接包含在角色资源中。

## 使用范围和后续验收

本批矢量图形、图标、场景、动画代码均为本项目原创，没有使用第三方角色、外部字体或第三方美术素材。可随本应用使用和修改。概念设计板为本次 AI 生成的风格参考，非教材内容。

已检查 81 种角色/阶段/单件服饰组合、动作复位、进化换形与换装保持、切换宠物取消未完成动作、减少动画、390px 手机布局和无外部请求。仍需在接入后的安卓 WebView 和真机上检查画面、触摸反馈及性能。此资源包不包含音效、配音或 3D 模型，本版采用 SVG 视觉互动。
