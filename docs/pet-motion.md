# 毛绒宠物动作第一版

## 动画稳定性修复

道具按动作条件创建：喂食仅苹果，玩耍仅小球，抚摸与待机无道具或爱心。检查同时覆盖正常动画与减少动画模式，并覆盖连续切换以排除道具残留。鼓励、答对和升级仍按各自动作显示对应奖励反馈。

互动开始、动作被打断和结束时，保留已解码的图片 DOM，使用动画 API 重播，避免重新创建整组图片导致短暂空白。移除挖空身体与独立旋转的耳、尾、爪裁片，改用完整原画动作与完整闭眼图切换；保留呼吸、抚摸、喂食、玩耍、庆祝和进化反馈。本版本不再使用局部裁片动作，以消除拼接缺口和表情裁切边缘。减少动画模式显示稳定完整原画。

回归检查：`MATHPET_TEST_URL=http://127.0.0.1:8766 node scripts/smoke-animation-stability.cjs`。该检查验证移动端动作开始、取消、结束时图片节点保留，并检查没有身体挖空和局部裁片。安卓屏幕是否仍闪烁需要设备验收。

以已确认的三宠物九形态原画为外观基准，生成九张独立透明 PNG。所有阶段保留幼年比例：幼年无配饰；初次进化增加小配饰；最终进化保留配饰并出现毛纹。旧版几何 SVG 宠物不再用于应用角色显示。

[查看实际动作预览页面截图](pet-motion-preview.png)。截图是静态画面；动作需下载离线 HTML 查看。

## 动作表现

| 动作 | 表现 | 时长 |
| --- | --- | --- |
| 呼吸待机 | 小幅缩放，影子随呼吸变化 | 3.8 秒循环 |
| 摸摸 | 轻轻向两边倾斜，浮出爱心 | 1.4 秒 |
| 喂食 | 点头，苹果靠近后消失 | 2.2 秒 |
| 玩耍 | 小跳、轻摇，皮球滚动 | 2.2 秒 |
| 答对庆祝 | 小跳与星光 | 1.5 秒 |
| 温柔鼓励 | 轻轻歪身，浮出爱心 | 1.6 秒 |
| 升级庆祝 | 小跳与扩散光圈 | 2 秒 |
| 进化 | 旧、新形态交叉淡入，光圈与星光 | 2.6 秒 |

历史第一版为整图动作；本轮已补充表情、咀嚼和局部裁片，具体范围见下方更新。没有配音和背景音乐。

## 应用接入

`PetPortrait.razor` 已替换旧宠物图，支持合法 `Species`、`Stage`、`Name` 和 `ReducedMotion` 参数，以及 `PlayAsync(action)`。参数仅允许三种宠物与三个阶段。显示当前主力宠物；三宠独立培养、20级、6级/13级进化及旧存档迁移已接入。

家园喂食成功、玩耍、清洁/抚摸触发对应动作。食物不足或吃饱不会播放成功喂食；成长阶段变化播放进化，离开页面销毁组件会取消动作。普通动作结束回到待机，后发动作取消先前动作，避免重复播放。预览可测试全部三宠物与全部动作；答对和鼓励已绑定练习反馈，实际跨等级触发升级，跨阶段触发进化。

减少动画支持预览开关、组件参数及系统 `prefers-reduced-motion`，通过静态特效给出反馈。进化立即显示新形态，避免旧图盖住新图。

## 打包与查看

```bash
python3 scripts/package-pet-motion.py
```

生成 `artifacts/mathpet-motion-preview.html` 和 `artifacts/mathpet-motion-assets.zip`。HTML 内嵌全部角色图和特效，离线打开，无需服务器或额外文件。资源包包含 PNG、动作 CSS、清单、预览和本文；GitHub Actions 产物名为 `mathpet-pet-motion`。

清单记录每张 PNG 的 SHA-256、尺寸与非透明边界，打包检查图像未被修改。图片由本次 imagegen 生成，不通过程序裁剪或重绘。不同形态为独立生成素材，可能有微小姿态与毛发细节差异；进化采用交叉淡入平滑衔接。素材需在安卓真机 WebView 接入后继续验收性能和触摸体验。

已通过54组角色/阶段/互动组合、6次进化、动作取消、真实呼吸变化、系统与手动减少动画、390px手机布局及无外部资源请求检查。应用喂食、拒绝喂食、成长进化、连续互动和离开页面取消也已验证；60项核心规则测试与完整浏览器流程通过。尚未在安卓真机运行验收。

## 本轮更新

应用已接入三只独立宠物、等级、衣饰和表现设置。新资源包含18张底图/闭眼表情PNG、9件手绘衣饰图集、14个图标图集、3张手绘家园。初期底图复用幼年外形并叠加小配饰，最终底图仅增加毛纹，体型不放大。

动作使用轻量CSS裁片与遮罩：耳、尾、爪轻摆，闭眼表情叠层眨眼、摸摸闭眼、喂食闭口切换咀嚼。配饰独立叠加，背包在后层。这里是固定二维姿态的轻量实现；不称为骨骼动画或多角度动作。短音效由浏览器音频接口合成，可静音；减少动画设置停用连续呼吸/局部动作。
