# 验收版规则（存档版本4）

## 教学与闯关

年级 → 学期 → 单元 → 知识点 → 讲解 / 例题 / 引导练习 / 独立练习 / 闯关。自由跨年级学习。知识点已掌握需每个题型模板累计至少两次独立正确、已有通关星级且没有待解决错题。

普通练习不限时；主课程闯关每题按题库设定45～120秒，切后台不会冻结，超时仍可作答并计入独立通关，只失去限时奖励。独立正确达到题数的三分之二（向上取整）通过；全部独立正确三星，达到80%（向上取整）二星，其余已通过为一星。使用提示不计入独立通关题数。

错题复习出相似题，独立正确后移除原错题，使用提示则保留。答错不扣积分。等值写法按数值判分；无法识别的格式、数值正确但不符合最简分数要求时提示修改，不记录错题或答题次数。

## 积分与学习经验

题目积分为四舍五入（10×年级系数×难度×提示系数×重复系数），答对最低1分。年级系数依次1、1.15、1.3、1.5、1.75、2。主课程题库普通题难度1、进阶题1.25；旧样例有1.2。提示系数0.6、重复系数0.3；首次限时独立正确额外2分。重复按具体题目ID判断。

首次通过每个知识点、单元或学期关，奖励20×年级系数（取整），不重复发放。每天首次完成每日练习额外10分，跨年级共享一次资格，日期取设备本地日期。题目提交后立即获得积分；退出保留题目积分，未完成不发结算奖励。

学习经验与积分分开：首次独立正确6、首次提示后正确4、重复独立正确3、重复提示后正确2，答错或格式重试0。完整结束一轮时结算，奖励给开始时锁定的宠物；通关及每日额外积分不转经验。重复提交、重复结算不会重复奖励。

## 宠物、等级与照顾

猫、兔、狐狸免费使用，新增小狗1200、小熊猫2500、水獭4000积分解锁，价格不影响基础成长能力。各自保存名字、等级、饱腹、心情、穿搭和每日培养记录。积分、食物、玩具、衣饰、房间库存共享。

等级1～20，6级初次进化、13级最终进化。L级到L+1级经验为35+5L+2L²；累计6级360、13级2110、20级6555。新伙伴从0经验开始，新存档猫初始20。等级、经验不下降，不死亡。

离开每满24小时，各宠物饱腹减少5、心情减少3，一次最多计算30天，饱腹最低30、心情最低40，最高均100。饱腹和心情不改变学习积分或经验。

## 存档迁移与测试余额

Version1～3迁移到Version4，保留学习记录、宠物名字、已购库存与余额，按旧等级和本级进度比例换算经验，保证不降级或退化；旧满级映射6555经验。已迁移存档不重复换算。旧食物和毛线球保留，新培养记录从零开始。

验收期间初始积分临时99999、食物2份。旧余额不覆盖；宠物家园的表现设置可补充至99999，余额更高时不减少。正常经济模拟使用120积分。正式版本去掉测试入口时不能未经授权扣旧余额或清除进度。

所有库存与进度保存在本设备，安卓视频使用应用内播放器、需要网络。学习与题库可离线。日期和存档没有服务器防篡改，不承诺抵抗修改设备时间或本地数据。
