# v0.1 规则

## 教学

年级 → 学期 → 样例单元 → 知识点 → 目标 / 讲解 / 分步例题 / 引导练习 / 独立练习 / 闯关。讲解自由浏览，不限制跨年级学习。知识点状态：未学、学习中、待巩固、已掌握。已掌握需要该知识点每道基础题至少独立答对两次、通过关卡且没有未解决错题；这是一版规则，后续可加入间隔复习验证。

练习不限时。闯关每题按照题库设定30～60秒，用实际经过时间计时，切后台不会冻结；超时仍能作答。三题中独立答对两题通过，独立答对两题为两星、三题为三星。提示过的题不计入独立通过数量，但可获得题目积分。退出保留已发放的题目积分，放弃完成奖励。未完成会话暂不支持关闭应用后续答。

错题记录错误输入、次数和时间。复习出配套相似题；独立答对后移除原错题，使用提示则保留。相似题答错仍更新原错题，避免一对题产生重复记录。

## 积分

- 题目积分 = 四舍五入(10 × 年级系数 × 难度系数 × 提示系数 × 重复系数)，最低1分。
- 一到六年级系数：1、1.3、1.6、2、2.5、3。应用/进阶样例难度系数1.2，其余1。
- 提示系数：用提示为0.6，否则1。重复系数：以前做对过为0.3，否则1。
- 闯关首次独立做对且未超时额外2分；重复做对无速度奖励。
- 首次通过一个知识点关卡：20 × 年级系数，之后不重复发放。
- 每天首次完成每日练习额外10分，以设备本地日期为准，跨年级只领一次。
- 答错不扣分；提示不收费。未提交、重复提交不能领取积分。完成结算只能发放一次。

完全离线，未使用服务器校验设备时间或防篡改，不承诺抵抗修改本地存档、时钟等行为。

## 宠物

初始赠送120积分、2份食物。三只宠物各自保存名字、经验、饱腹、心情和穿搭。积分、食物、玩具及衣饰库存共享；主力选择决定当前照顾对象，练习开始时锁定经验奖励宠物，途中切换也不会改收款对象。

宠物等级1–20；达到6级初次进化、13级最终进化，体型不扩大。幼年无进化装饰，初次进化有小配饰，最终进化增加毛纹。累计经验门槛：(等级−1)×25+(等级−1)×等级×5÷2，满级1425经验。练习完成获得题目积分总额一半的经验（取整，重复题积分减少也同步降低经验）；高年级通常获得更多。喂食增加20饱腹、2经验，满饱腹不消耗食物。等级、经验不会下降。

每天未见面，各宠物饱腹减少5、心情减少3；最低分别30与40。免费玩耍心情+8，有永久玩具+15；清洁/抚摸心情+5。互动不产生积分。

衣饰有头饰、衣服、饰品三个槽位，购买一次、三宠共享库存但各自穿搭。卸下饰品可隐藏进化配饰，“恢复进化配饰”恢复默认装饰。三家园可切换，小屋购买后解锁春日与星光背景。衣饰不影响判分或练习资格。

单元综合关至少3题、学期综合关最多12题，综合跨知识点选题；成绩保存独立key，避免覆盖知识点成绩。知识点关、单元关、学期关都需要独立完成才能通关；用提示或超时不会扣已得积分。

旧Version1存档自动迁移到三宠Version2，保留积分、错题、学习记录、原猫名字和旧进化状态。旧衣饰和小屋转换到新结构。减少动画、声音开关保存在设备。视频需要网络，在B站外部打开；学习与题库本身可离线使用。
