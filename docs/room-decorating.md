# 房间装饰验收

宠物家园 → 小岛商店：分别解锁背景、购买装饰；进入背包后点击“摆放装饰”或“收起装饰”。商店和背包都有当前房间预览。

新存档初始积分临时为 99999。升级后保留旧余额，宠物家园 → 表现设置 → “测试：补充积分至 99999”可补充测试余额，不需要重置进度。余额超过 99999 时保持原值。正式发布前需要恢复常规初始积分并移除按钮。

## 验收重点

1. 六套背景分别查看：暖木学习屋、春日花园、星空梦境、雨林、海洋、秋日。单独解锁背景不会赠送或自动摆放装饰。
2. 装饰无需解锁同主题背景就能购买，每件购买一次可反复摆放和收起。
3. 每套五件装饰组成完整主题，也可在任意背景上混搭；换背景不挪动、不移除装饰。
4. 允许不同装饰重叠，每件最多摆放一个；“收起全部装饰”保留库存。
5. 切换主宠物、重启应用后，房间与装饰保持原样。
6. 旧衣服和书包不再穿在宠物身上，购买记录按原价退款一次；头饰和铃铛等保留。原已解锁的背景和学习、宠物进度保留。
7. 手机和电脑采用统一 16:10 画布，背景、装饰与宠物一起缩放。

## 实现与验证

`RoomCatalog.cs` 定义商品、价格、固定中心坐标、尺寸与图层；`RoomScene.razor` 合成背景、装饰和宠物。资源包含六张背景和三十件装饰（部分采用透明图集，按物体间隙显示完整边缘），位于 `src/MathPet.UI/wwwroot/room-assets/`。

核心测试 `RoomDecorationTests.cs` 覆盖独立购买、余额限制、混搭、存档恢复、旧衣服退款不重复、异常存档拒绝，以及测试余额保留。

启动 `MathPet.Web` 后运行：

```bash
MATHPET_TEST_URL=http://127.0.0.1:8783 node scripts/smoke-room-decor.cjs
```

浏览器回归通过实际操作购买全部背景与装饰，检查图片加载、混搭、切宠物、重载后恢复及手机坐标，输出房间截图到 `artifacts/room-preview/`。

本次验证：121 项核心测试通过；房间浏览器回归通过，覆盖 390、768、1280 像素宽度；原有完整界面回归通过。实际截图保存在 [主题方案](room-theme-proposal.md)。Android 构建与 APK 签名验证通过，设备效果由用户验收。
