# 等值答案与格式重试

数值题用精确分数运算比较，接受整数、小数、等值分数、全角数字，以及数字后一个“万”或“亿”倍率。例如 20000、2万、0.0002亿等值；1.25万等于12500。允许题目指定单位省略，填写时必须匹配；本轮不自动进行不同物理单位的换算。

判分分为正确、已识别的错误答案、需要修改格式三种结果。无法识别的写法、无效时刻/坐标或无效选项编号，提示修改，不完成本题、不增加答题次数、不改变积分、不新建或更新错题。提示使用次数和闯关计时继续保留，重填后只结算一次。

要求最简分数时，数值正确但未约分或使用小数，提示按要求改写；数值本身错误仍正常判错。分类操作保留按实际选择集合判分，选择了错误图形或重复图形仍判错。

暂不解析中文数字（如“两万”）、混合数量写法（如“2万3千”）、任意算式或跨物理单位换算。此类无法识别的输入提示重填，不当成数学错误。本轮未把题目批量改成选择题，也未添加开放题的多答案规则；后续按题型模板审核。

检查：`dotnet test tests/MathPet.Core.Tests`；启动网页宿主后执行 `MATHPET_TEST_URL=http://127.0.0.1:8766 node scripts/smoke-answer-format.cjs`。浏览器回归使用截图对应的真实题目，检查“2万”判对以及格式重试不会误记错题。
